# 计算机联锁模拟仿真系统设计方案

## 1. 总体设计

本系统采用纯软件方式实现计算机联锁模拟环境，运行在一台计算机上的浏览器中。系统由上位机操作台、后台联锁逻辑和室外设备仿真三部分组成，三者通过统一的前端状态机连接：操作台下发按钮命令，联锁逻辑检查区段、道岔、信号和故障状态，站场图实时显示信号开放/关闭、道岔位置、区段锁闭/占用/出清以及列车运行过程。

技术平台为 Next.js、React、TypeScript 和 SVG。站场静态数据、信号机、道岔、区段、室外设备和进路表集中定义在 `lib/interlocking-data.ts`；联锁状态机位于 `components/interlocking-provider.tsx`；上位机界面由 `components/station-yard.tsx`、`components/control-panel.tsx` 和 `components/info-panel.tsx` 组成。

## 2. 站场图设计

站场图采用 SVG 坐标系绘制，覆盖清晰站场示意图中的基本元素：左右区间边界 JXG/JSG，左端 IIAG、右端 IIBG，站内 3G、IIG、IG 三条股道，1/2/3/4/5 五组道岔，X/S 进站信号机，左侧 S3/SII/S1 出站信号机，右侧 X3/XII/X1 出站信号机，D1/D2 调车信号机，以及安全线和 PZA 防护设备标识。

区段使用颜色编码表达状态：灰色为空闲，黄色为进路锁闭，红色为车列占压。道岔尖轨按定位/反位显示不同方向和颜色，锁闭或封锁时在道岔旁显示状态标识。信号机按红、绿、黄、月白、蓝等灯色显示；断丝故障时灯位熄灭并叠加红色故障标识。

## 3. 上位机操作功能

操作台支持以下按钮作业：

- 进路操作：点选始端信号机后，点选终端信号机或股道，办理列车接车、发车、通过和调车进路。
- 道岔操作：单操、单锁、单解、封锁、解封，以及道岔总定、道岔总反。
- 进路取消：总取消用于未接近进路的立即解锁，总人解用于已接近进路的延时人工解锁。
- 仿真控制：模拟列车运行，驱动区段占压、出清和进路自动解锁。
- 故障仿真：信号断丝与恢复信号，演示室外信号设备故障对进路办理的影响。
- 辅助显示：当前活动进路列表、联锁机在线状态、系统时间、操作提示、报警信息和人工解锁倒计时。

## 4. 联锁逻辑

联锁逻辑以进路表为核心。每条进路定义始端、终端、类型、名称、需要锁闭的区段、要求的道岔位置、信号开放灯色和列车运行路径。办理进路时，系统按以下顺序检查：

1. 始端信号机是否存在断丝故障。
2. 进路区段是否均为空闲。
3. 进路所需道岔是否被封锁。
4. 已单锁道岔的位置是否满足进路要求。

检查通过后，系统锁闭进路区段，按进路要求转换道岔，开放始端信号，并记录活动进路。当前进路表覆盖 X/S 两端接车进路，S3/SII/S1 与 X3/XII/X1 的各股道发车进路，X-S 和 S-X 两个通过进路，以及 D1/D2 至 IG、IIG、3G 的站内调车进路。

取消和解锁逻辑分两类：未接近进路可总取消并立即解锁；列车已接近的进路需要总人解并经过 30 秒倒计时后解锁。列车模拟运行时，区段按路径顺序由锁闭转为占用，再转为空闲；列车出清后信号关闭，活动进路删除。

## 5. 仿真功能

室外信号设备仿真包括开放、关闭和断丝。开放由进路建立触发，关闭由总取消、人工解锁或列车出清触发，断丝由操作台按钮设置。断丝时站场图显示灯位熄灭和故障标识，联锁逻辑禁止以故障信号为始端开放信号。

室外道岔设备仿真包括定位、反位、动作延时、锁闭和封锁。单操道岔时系统显示动作中状态，0.5 秒后完成转换；锁闭进路内的道岔禁止单操；封锁道岔不能被进路使用。

室外轨道电路仿真包括车列占压和出清。模拟列车运行后，进路区段按列车位置逐段切换为占用和空闲，用于演示进路解锁过程。

## 6. 测试与验收

项目提供 `pnpm test:requirements` 作为课程需求验收脚本，检查站场元素、列车/调车/通过进路、信号断丝仿真、道岔动作仿真、轨道占压出清仿真和设计方案文档是否存在。项目还应通过 `pnpm build`，证明模拟软件可构建运行。

建议演示流程如下：

1. 上电解锁，确认所有设备恢复初始状态。
2. 办理 X 至 II 道接车进路，观察区段锁闭、道岔定位、X 信号开放绿灯。
3. 模拟列车运行，观察区段占压、出清和进路自动解锁。
4. 办理 X 至 S 通过进路，观察通过作业完整路径。
5. 办理 D1 至 IG/IIG/3G 调车进路，观察调车信号月白开放。
6. 对某信号机设置断丝，再尝试以其为始端办理进路，确认联锁拒绝开放信号。
7. 对进路内道岔尝试单操，确认联锁禁止；对空闲道岔执行单操，确认 0.5 秒动作后到位。
8. 对未接近进路执行总取消，对已接近进路执行总人解，确认 30 秒倒计时后解锁。
